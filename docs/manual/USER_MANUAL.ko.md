## 💡 1. Stepwise란 무엇인가요? (30초 요약)

**Stepwise(스텝와이즈)**는 사내 ERP(SAP GUI, 더존 등)나 사내 웹 포털에 매일 반복해서 수작업으로 입력하던 대량의 엑셀 표 데이터를 **사람 대신 마우스와 키보드를 움직여 안전하고 신속하게 입력해 주는 데스크톱 자동화 도구**입니다.

### ❓ 일반 매크로(RPA)와 무엇이 다른가요?

| 구분 | 일반 키보드/마우스 매크로 | Stepwise (스텝와이즈) |
| :--- | :--- | :--- |
| **인터넷/시스템 지연 시** | 화면이 안 떴는데도 무작정 클릭하여 **엉뚱한 곳에 입력되거나 에러 발생** | 화면 모양을 직접 눈으로 확인(`Guard`)하고 뜰 때까지 기다린 후 입력 |
| **오류 발생 시** | 무작정 다음 줄로 넘어가서 **데이터 누락/중복 사고** 유발 | 즉시 멈추고(`Fail-Fast`) 어디서 왜 멈췄는지 명확히 알림 |
| **원본 엑셀 파일** | 원본 파일을 직접 수정하다 파일 손상 위험 | **원본 엑셀은 1바이트도 건드리지 않음** (별도 결과 CSV에 실시간 저장) |
| **비상 멈춤** | 멈추기 어려워 전원 버튼을 누르는 경우 발생 | 키보드 **F12**만 누르면 0.01초 만에 즉각 비상 정지 |
| **설치 권한** | 관리자(Admin) 권한이 필요해 IT 부서 승인 필요 | 사내 PC **관리자 권한 없이 일반 계정에서 즉시 실행** |

## 🚀 2. 5분 완성 튜토리얼 (첫 자동화 만들기)

Stepwise를 처음 켜셨나요? 가장 기본적인 "엑셀 파일 열고 화면에 순서대로 입력하기"를 5분 안에 따라 해보세요!

```
[ 전체 진행 순서 ]
1. 엑셀 데이터 파일 선택  ➡️  2. 3구역 이해하기  ➡️  3. 클릭/입력 스텝 만들기  ➡️  4. 실행 및 확인
```

### 1단계: 엑셀 데이터 파일 불러오기
1. 상단 메뉴나 우측 **[Data Preview]** 탭에서 **[Choose Data File...]** 버튼을 누릅니다.
2. 자동화할 엑셀(`.xlsx`) 또는 `.csv` 파일을 선택합니다.
   - 예시 엑셀: `거래처코드`, `품목코드`, `수량`, `단가` 열이 있는 파일
3. 하단에 엑셀 내용이 표로 깔끔하게 뜨고, 상단에 `[+ {거래처코드}]`, `[+ {수량}]` 등의 **파란색 열 변수 버튼**들이 나타납니다.

---

### 2단계: 화면의 3구역(Pipeline) 이해하기
가운데 작업 창을 보면 3개의 큰 폴더 구역이 있습니다:

1. **📁 SETUP (초기 1회 실행)**:
   - ERP 프로그램 창을 활성화하거나, 메뉴 번호(T-Code)를 입력해 조회 화면을 여는 등 **맨 처음에 딱 한 번만 해야 하는 동작**을 넣습니다.
2. **📁 PER ROW (엑셀 각 행마다 반복 실행)**:
   - **가장 핵심이 되는 구역입니다.** 엑셀의 1번째 줄부터 마지막 줄까지 행마다 반복해서 입력할 클릭, 타이핑 동작을 넣습니다.
3. **📁 CLEANUP (완료 후 1회 실행)**:
   - 모든 엑셀 행 입력이 끝난 뒤 창을 닫거나 완료 알림을 띄우는 등 **마지막에 한 번만 실행할 동작**을 넣습니다.

---

### 3단계: 마우스 클릭 및 글자 입력 스텝 만들기

#### ① 마우스로 입력창 클릭하기
1. 왼쪽 아래의 **[+ Click]** 버튼을 누릅니다.
2. `PER ROW` 구역에 새로운 클릭 동작이 추가됩니다.
3. 오른쪽 **[Properties]** 패널에서 **[Pick (F8)]** 버튼을 누릅니다.
4. 마우스 커서가 십자선 모양으로 바뀌면, **내가 입력하고 싶은 ERP 입력창을 마우스로 클릭**합니다. (화면의 X, Y 좌표가 자동으로 들어갑니다!)

#### ② 엑셀 변수 글자 타이핑하기
1. 왼쪽 아래의 **[+ Type]** 버튼을 누릅니다.
2. 오른쪽 **[Properties]** 패널의 `Text to type:` 입력칸을 클릭합니다.
3. 우측 상단이나 Data Preview에 있는 **`[+ {거래처코드}]` 버튼을 쏙 누르면** 텍스트 창에 `{거래처코드}`가 자동으로 입력됩니다.
4. *팁*: 필요하다면 `{거래처코드} - 정기발주`처럼 엑셀 변수 뒤에 고정 텍스트를 함께 써도 됩니다.

#### ③ 키보드 Enter나 Tab 누르기
1. 다음 칸으로 이동하려면 **[+ Key]** 버튼을 누르고 `Tab` 또는 `Enter`를 선택합니다.

---

### 4단계: 실행 및 비상 정지 연습하기

1. 상단 툴바의 초록색 **[▶ Run]** 버튼(또는 **F5**)을 누릅니다.
2. Stepwise가 엑셀 첫 번째 줄부터 차례대로 화면을 클릭하고 데이터를 입력하기 시작합니다.
3. **🚨 비상 정지(F12)**:
   - 동작 중 마우스가 이상한 곳으로 가거나 멈추고 싶다면, 주저하지 말고 키보드 맨 위의 **`F12`** 키를 누르세요.
   - 0.01초 만에 모든 동작이 안전하게 정지됩니다.

## 🛡️ 3. 실패 없는 안전장치 만들기 (Guard & Verify)

사내 시스템은 네트워크 상태나 서버 부하에 따라 로딩 창이 늦게 뜨거나 에러 팝업이 뜰 수 있습니다. Stepwise의 **시각 안전장치**를 사용하면 100% 안심하고 자동화를 켜둘 수 있습니다.

### 1) Guard (사전 확인): "창이 열렸는지 보고 클릭해라!"
- 액션 속성창에서 **`[✓] Enable Guard`**를 체크합니다.
- **[Capture (F9)]** 버튼을 누르면 화면이 순간 정지(Freeze)됩니다.
- 정상적으로 열려 있어야 하는 창의 **제목표시줄이나 고유 아이콘을 마우스로 네모나게 드래그**합니다.
- **효과**: 매크로가 해당 스텝을 실행하기 전, 방금 캡처한 이미지가 화면에 실제로 나타났는지 먼저 확인합니다. 만약 로딩 중이라면 나타날 때까지 기다리며, 타임아웃이 지나도 안 뜨면 안전하게 멈춥니다.

### 2) Verify (사후 검증): "정상적으로 저장되었는지 확인해라!"
- 저장 버튼을 누르는 클릭 스텝에 **`[✓] Enable Verify`**를 체크합니다.
- 저장 후 나타나는 **"전표가 성공적으로 전기되었습니다"** 메시지 영역을 **[Capture (F9)]**로 지정합니다.
- **효과**: 저장이 정상적으로 완료되었는지 화면 눈으로 직접 확인한 뒤에야 다음 엑셀 행으로 넘어갑니다.

## 📊 4. 대량 실행 및 결과 확인 (결과 보존 원칙)

수백 건의 데이터를 돌리다가 퇴근하셔도 걱정 없습니다.

1. **원본 파일 100% 보호**:
   - Stepwise는 불러온 원본 엑셀 파일을 절대 수정하거나 덮어쓰지 않습니다.
2. **실시간 결과 CSV 자동 생성**:
   - 매크로가 실행되는 동안 `결과_파일명_20261004.csv` 파일이 실시간으로 디스크에 기록됩니다.
   - 각 줄마다 `SUCCESS`, `FAILED`, 소요 시간, 실패 원인이 빠짐없이 기록됩니다.
3. **실패한 줄만 이어하기 (Resume)**:
   - 만약 45번째 줄에서 시스템 팝업으로 멈췄다면, 팝업을 닫고 45번째 줄의 마우스 우클릭 메뉴에서 **[Retry this row]** 또는 **[Run from this row]**를 누르면 1번부터 다시 할 필요 없이 바로 이어서 작업할 수 있습니다.

## ⚡ 5. 속도 조절 & 실무 꿀팁

### 1) 사내망이 유난히 느린 날
- 툴바 우측의 속도 버튼을 클릭하세요:
  - **Normal**: 기본 속도 (권장)
  - **Slow (+0.5s)**: 모든 클릭과 타이핑 사이 0.5초 추가 여유 대기
  - **Very slow (+1.0s)**: 사내망 지연이 심한 날 1초 추가 대기

### 2) 화면 배율(DPI)과 창 위치 맞추기
- 마우스 좌표(F8)를 찍었을 때의 **대상 프로그램(SAP 등) 창 크기와 위치를 모니터에 고정**해 두는 것이 가장 안전합니다. (창을 최대화하거나 항상 같은 모니터에 두세요)
- Stepwise 하단 상태표시줄을 보면 내 모니터 해상도와 배율(예: `1920x1080 @100% ✅`)이 매크로 저장 당시와 일치하는지 자동으로 감지해 초록색 불로 알려줍니다.

## ❓ 자주 묻는 질문 (FAQ)

**Q1. 비밀번호를 매크로 입력칸에 넣어도 되나요?**  
> ⚠️ **절대 안 됩니다.** 사내 보안 규정상 비밀번호는 매크로 스텝에 텍스트로 저장하지 마시고, 매크로 시작 전 수동으로 로그인한 상태에서 자동화를 실행해 주세요.

**Q2. 한글이나 특수문자가 깨져서 입력돼요.**  
> `+ Type` 스텝의 속성창에서 Typing Mode를 **`Paste (Clipboard)`**로 설정해 보세요. Stepwise는 윈도우 클립보드를 통해 한글, 폴란드어, 한자 등 전 세계 모든 유니코드를 100% 완벽하게 붙여넣습니다.

**Q3. 다른 작업을 하면서 백그라운드로 돌릴 수 있나요?**  
> Stepwise는 사람의 마우스와 키보드를 직접 대신하는 도구이므로, 실행 중에는 마우스를 건드리지 않는 것이 좋습니다. 자동화가 도는 동안에는 잠시 커피를 드시거나 다른 모니터를 사용해 주세요!
